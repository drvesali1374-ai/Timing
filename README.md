# Timing — پلتفرم ماژولار زمان‌سنجی صنعتی، مطالعه کار و بالانس خط تولید

وب‌اپلیکیشن حرفه‌ای و توسعه‌پذیر برای **زمان‌سنجی مستقیم با کرنومتر، مطالعه کار، تعیین زمان نرمال/استاندارد، نمودارهای فرایندی OPC/FPC، بالانس خط تولید و برآورد نیروی کاری** — فارسی و راست‌به‌چپ در اولویت، آماده استقرار تک-سروری (PWA نصب‌پذیر).

## قابلیت‌های کلیدی

- **مدیریت پروژه‌های ایزوله** با نقش‌ها (owner/editor/recorder/viewer) و ممیزی کامل append-only.
- **پیکربندی پویا:** خانواده/پارامتر سفارشی + فرمول DSL امن (بدون eval) با نسخه‌بندی semver — بدون تغییر کد.
- **کارگاه فرم‌ساز** با شرط‌های نمایش/الزام پویا و ثبت مقادیر.
- **طراح نمودار OPC/FPC** گرافیکی (React Flow): خروجی SVG/PNG/چاپ RTL + اعتبارسنجی زنده + تاریخچه نسخه + variant مقایسه‌ای.
- **دستیار آفلاین** قواعد-محور (۱۱ قاعده پیشنهاد با دلیل + کتابخانه دانش محلی) — بدون اینترنت.
- **کرنومتر مهندسی‌شده:** `performance.now()` یکنواخت، مدیریت اختلال (auto-pause در مخفی‌شدن تب، پرچم بازیابی پس از reload)، اصلاح با دلیل، idempotency تحت قطعی و رقابت دو کلاینت.
- **تحلیل آماری:** آمار توصیفی/CV/چندک، دو قاعله پرت (IQR/z-score) جدا از حذف، کفایت نمونه، زنجیره زمان با دو قرارداد مجاز (on-normal/on-standard) و ردیابی فرمول نسخه‌دار.
- **بالانس خط:** سه الگوریتم قطعی (LCR · RPW Helgeson–Birnie · Kilbridge–Wester) + تخصیص دستی با اعتبارسنجی قیود سخت/نرم + Yamazumi/OBC + مقایسه سناریو + برآورد نیروی نظری/عملیاتی.
- **خروجی‌ها:** CSV (BOM فارسی) · XLS (SpreadsheetML RTL) · JSON با بلوک ردیابی کامل · چاپ A4 RTL.
- **PWA:** Service Worker (پوسته آفلاین + دارایی کش‌اول؛ API هرگز کش نمی‌شود) + manifest فارسی + نصب‌پذیری.

## شروع سریع

```bash
bun install
cp .env.example .env          # DATABASE_URL + NEXTAUTH_SECRET بسازید
bun run db:push
bun run seed                  # کاربر نمونه: demo@timing.local / demo1234
bun run dev                   # → http://localhost:3000
```

راهنمای کامل نصب/استقرار/پشتیبان‌گیری/عیب‌یابی: **`docs/DEPLOYMENT_FA.md`**
راهنمای کاربر فارسی: **`docs/USER_GUIDE_FA.md`**

## اصول کلیدی محصول

- **پیش‌فرض مهندسی‌شده + شخصی‌سازی حداکثری:** پروژه جدید هرگز خالی ایجاد نمی‌شود؛ پروفایل پیش‌فرض واقعی و قابل ویرایش است.
- **صداقت روش‌شناختی:** استانداردهای رسمی، روش‌های مرجع و مقدارهای پیشنهادی/وابسته به کارخانه از هم جدا می‌مانند؛ هیچ ضریبی بدون منبع «استاندارد جهانی» جلوه داده نمی‌شود.
- **استقلال پروژه‌ها:** ویرایش یک پروژه هیچ پروژه دیگری را تغییر نمی‌دهد؛ مجوزسنجی سمت سرور در همه APIها.
- **قابلیت ردیابی:** هر نتیجه به نسخه پیکربندی، نسخه فرمول و مشاهدات ورودی ارجاع دارد.
- **تست بدون شاهد، پذیرفته نیست:** وضعیت هر معیار در `docs/PHASE_STATUS.md` با شاهد ثبت می‌شود.
