# Timing — پلتفرم ماژولار زمان‌سنجی صنعتی، مطالعه کار و بالانس خط تولید

وب‌اپلیکیشن حرفه‌ای و توسعه‌پذیر برای **زمان‌سنجی مستقیم با کرنومتر، مطالعه کار، تعیین زمان نرمال/استاندارد، نمودارهای فرایندی OPC/FPC، بالانس خط تولید و برآورد نیروی کاری** — فارسی و راست‌به‌چپ در اولویت.

## اجرای محیط توسعه

```bash
bun install          # نصب وابستگی‌ها
bun run dev          # سرور توسعه روی پورت 3000
bun run lint         # بررسی کیفیت کد
node scripts/validate-phase0.mjs   # اعتبارسنجی تحویل‌دادنی‌های فاز صفر
```

> نمونه اولیه قابل بررسی در مسیر `/` شامل ۸ نمای اصلی است: مدیریت پروژه‌ها، ایجاد پروژه با انتخاب پروفایل،
> کارگاه پیکربندی، صفحه زمان‌سنجی (با نمایش زنده مفهوم کرنومتر monotonic)، نمودارهای OPC/FPC،
> تحلیل زمان، بالانس خط (Yamazumi) و گزارش‌ها.

## اصول کلیدی محصول

- **پیش‌فرض مهندسی‌شده + شخصی‌سازی حداکثری:** پروژه جدید هرگز خالی ایجاد نمی‌شود؛ پروفایل پیش‌فرض واقعی و قابل ویرایش است.
- **صداقت روش‌شناختی:** استانداردهای رسمی، روش‌های مرجع و مقدارهای پیشنهادی/وابسته به کارخانه از هم جدا می‌مانند؛ هیچ ضریبی بدون منبع «استاندارد جهانی» جلوه داده نمی‌شود.
- **استقلال پروژه‌ها:** ویرایش یک پروژه هیچ پروژه دیگری را تغییر نمی‌دهد؛ مجوزسنجی سمت سرور در همه APIها.
- **قابلیت ردیابی:** هر نتیجه به نسخه پیکربندی، نسخه فرمول و مشاهدات ورودی ارجاع دارد.
- **تست بدون شاهد، پذیرفته نیست:** وضعیت هر معیار در `docs/PHASE_STATUS.md` با شاهد ثبت می‌شود.
