# زمان‌سنجی صنعتی — نرم‌افزار مطالعات زمان استاندارد خطوط تولید

نرم‌افزار تحت وب برای مطالعات زمان (Time Study) در صنعت، مطابق سند نیازمندی‌های محصول (`PRD_Document.txt`).
**کارکرد کاملاً آفلاین در شبکه داخلی** — بدون احراز هویت (یک کارشناس محلی)، بدون هیچ درخواست خارجی، داده‌ها روی دیسک محلی سرور.

> قواعد بنیادین محصول:
> - هر پروژه = **یک خط تولید + یک محصول**
> - داده خام هرگز بدون تصمیم کاربر تغییر نمی‌کند؛ رکورد مشکوک فقط «علامت‌گذاری» می‌شود
> - حذف دائمی است اما با **نشانگر حذف (Deletion Marker)** تا هنگام Restore بازنگردد
> - محاسبات با snapshot تنظیمات ثبت می‌شود تا تغییر تنظیمات، نتیجه تاریخی را بی‌صدا عوض نکند

## راه‌اندازی

پیش‌نیاز: [Bun](https://bun.sh) (نسخه ۱.۱ یا بالاتر)

```bash
# ۱) نصب وابستگی‌ها
bun install

# ۲) تنظیمات محیط (مسیر پایگاه داده SQLite)
cp .env.example .env

# ۳) ایجاد پایگاه داده از اسکیما
bun run db:push

# ۴) اجرای محیط توسعه روی پورت 3000
bun run dev
```

اجرای تولید (سرور شبکه داخلی):

```bash
bun run build
bun run start
```

برنامه **تک‌مسیره** است (`/`) و ناوبری داخلی با hash انجام می‌شود؛ همه APIها زیر `/api/` قرار دارند.

### آزمون‌های الزامی PRD

```bash
# سرور در حال اجرا روی پورت 3000 لازم است
bun scripts/verify-phase1-2.ts   # فاز ۱ و ۲ — ۱۰۲ سنجه
bun scripts/verify-phase3.ts     # فاز ۳ — ۸۳ سنجه
bun scripts/verify-phase4.ts     # فاز ۴ — ۶۸ سنجه
```

فاز ۱ و ۲ (۱۰۲ سنجه): ۵ فرمول اجباری وستینگهاوس/مجازها/روش پیوسته/فواصل هم‌پوشان، آمار، MAD، ارقام فارسی و تقویم جلالی،
جریان کامل API (ساختار، ارث‌بری مجازها، ارزیابی، Idempotency، کنترل هم‌زمانی، کپی، بسته، حذف دائمی، Restore با نشانگرها،
وضعیت مراحل، نهایی‌سازی) — خروجی نهایی باید «همه آزمون‌ها موفق بودند» باشد.

فاز ۳ (۸۳ سنجه): آزمون‌های مرجع **B6** (قرائت‌های ۸، ۲۰، ۴۵ → مدت‌های ۸، ۱۲، ۲۵) و **B7**
(بازه‌های [۰،۸]+[5،25] → مجموع ۲۸، سپری‌شده ۲۵) از طریق API واقعی + زنجیرهٔ پیوسته بین چرخه‌ها،
ردّ قرائت نزولی/زمان منفی/بازهٔ نامعتبر، Paste با پیش‌نمایش و دو حالت ثبت، خروج از محاسبه بدون حذف خام،
بازگردانی چرخهٔ حذف‌شده (Undo)، تغییرناپذیری روش جلسه، جلسهٔ بستهٔ فقط‌خواندنی، جلسهٔ جدید مستقل،
وضعیت مرحلهٔ زمان‌سنجی و ارقام فارسی.

فاز ۴ (۶۸ سنجه): آزمون‌های مرجع **B1** (OT=۸٫۳۰ × R=۱٫۰۹ → NT=۹٫۰۴۷)، **B2** (NT=۹٫۰۴۷، A=۰٫۱۵ →
روش ۱: ۱۰٫۴۰۴۰۵ / روش ۲: ≈۱۰٫۶۴۳۵۲۹)، **B5** (خروج از محاسبه: خام حفظ + خارج از میانگین) و
**B7** (تغییر پارامتر: Snapshot قبلی حفظ + وضعیت STALE) از طریق API واقعی + آمار توصیفی کامل
(SD/واریانس/CV/چارک/IQR/CI-t؛ n<۲ → null نه صفر)، علامت‌گذاری مشکوک با MAD و امتیاز ثبت‌شده،
بازگشت شفاف به محاسبات، مقایسهٔ اپراتورها با R مشترک، هر دو روش تجمیع ۱۰.۱،
فعالیت هم‌پوشان (NEEDS_AGGREGATION_RULE، سپری‌شده=۲۵ نه ۲۸)، پیشرفت نمونه و Snapshot سه‌نسخه‌ای.

## معماری (پنج لایه)

```
src/
├── app/            # مسیرها + Route Handlers (API REST با Zod و خطاهای فارسی ساخت‌یافته)
├── application/    # سرویس‌های کاربردی (پروژه، ساختار، مجازها، ارزیابی، زمان‌سنجی، تحلیل، Snapshot محاسبات، تنظیمات)
├── domain/         # انواع دامنه + اعتبارسنجی ورودی + برچسب‌ها
├── calculation/    # موتور محاسبات خالص (فرمول‌های اجباری — بدون وابستگی به فریم‌ورک)
├── infrastructure/ # پشتیبان/Restore، تاریخچه، نشانگر حذف، سریال‌سازی بسته، داده Seed
├── views/          # نماها (SPA — Home و مراحل پروژه)
├── components/     # اجزای مشترک و چیدمان (شل، سایدبار مراحل، فوتر چسبان)
├── store/          # Zustand (ناوبری/نمایش)
└── lib/            # کلاینت API، قالب‌بندی، تقویم جلالی، ارقام فارسی
prisma/schema.prisma # مدل داده (UUID، Cascade صریح، فیلدهای snapshot)
```

### نکات کلیدی پیاده‌سازی

- **موتور محاسبات** (`src/calculation/`): `R = 1 + S + E + C + Cons`، `NT = OT × R`،
  `ST = NT × (1+A)` و `ST = NT / (1−A)` (با قید A < 1)، مشتق مدت‌ها از قرائت پیوسته،
  مجموع فواصل و زمان سپری‌شده چرخه هم‌پوشان، آمار توصیفی (SD/CV)، تشخیص غیرعادی MAD (فقط علامت‌گذاری).
- **Westinghouse**: جدول Seed با هشدار «نسخه رایج — نیازمند تأیید کارشناس»، ویرایش با
  «ذخیره به‌عنوان نسخه جدید» (محاسبات تاریخی به نسخه قبلی ارجاع می‌مانند)، ارزیابی هر عنصر یک‌بار
  و کپی از عنصر مشابه.
- **پشتیبان‌گیری**: خودکار زمان‌بندی‌شده با چرخش نسخه‌ها، دستی، حفاظتی پیش از Restore؛
  اعتبارسنجی checksum و نسخه ساختار؛ اعمال نشانگرهای حذف پس از Restore.
- **کنترل هم‌زمانی و Idempotency**: `expectedUpdatedAt` (409 در تعارض) و `x-change-id` (پاسخ کش‌شده).
- **آفلاین**: فونت Vazirmatn به‌صورت محلی بسته‌بندی شده (مجوز SIL OFL 1.1)،
  بدون CDN و بدون درخواست خارجی؛ تله‌متری Next.js غیرفعال (`.env`).
- **رابط کاربری**: فارسی RTL، تقویم شمسی و ارقام فارسی (قابل تغییر به میلادی/لاتین)،
  تم روشن/تیره، واکنش‌گرا (موبایل: جدول‌ها به کارت تبدیل می‌شوند)، راهنمای آیکونی هر فیلد با مثال.
