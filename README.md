# Timing — نرم‌افزار یکپارچه مطالعات صنعتی زمان و بهره‌وری خط تولید

وب‌اپلیکیشن فارسی و راست‌به‌چپ برای **تعریف خط تولید و ایستگاه‌ها، ثبت زمان‌های اندازه‌گیری‌شده، تحلیل مهندسی زمان (نرمال/استاندارد)، نمودارهای فرایندی OPC/FPC و بالانس خط** — طراحی‌شده برای کاربری که تجربه زمان‌سنجی ندارد اما داده‌های آماده دارد؛ در عین حال تمام قابلیت‌های تخصصی برای مهندسان مطالعه کار حفظ شده است.

## جریان اصلی محصول (مسیر ساده)

1. **ایجاد پروژه** — با تنظیمات آماده پیش‌فرض (ویزارد ۲گامی).
2. **خط و ایستگاه‌های کاری** — ورود سریع یا یک‌جا از Excel.
3. **فعالیت‌ها** — ورود گروهی با شناسه داخلی خودکار + اتصال به ایستگاه.
4. **نمودار فرایندی (اختیاری)** — OPC/FPC با ارتباط دوطرفه فعالیت↔گام.
5. **برگه ثبت زمان** — جدول فعالیت × نمونه؛ ورود دستی زمان‌های اندازه‌گیری‌شده (12.5 / ۱۲٫۵ / 00:12.5)، چسباندن از Excel، وقفه‌ها با علت.
6. **تحلیل مهندسی زمان** — میانگین/داده پرت/کفایت نمونه + زنجیره نماینده→نرمال→استاندارد.
7. **بالانس خط و گزارش نهایی**.

راهنمای قدم‌به‌قدم درون‌برنامه (۱۴ مرحله با مثال واقعی) + پروژه نمونه «خط مونتاژ پنل» (DEMO-102) این مسیر را زنده نشان می‌دهد. حالت «پیشرفته» تنظیمات تخصصی (گروه اطلاعات، فرمول‌نویسی DSL، …) را برای متخصصان باز می‌کند.

## وضعیت پروژه — نسخه ۱٫۱٫۰ (ADR-017)

| قابلیت | وضعیت |
|---|---|
| هسته، پروژه‌ها، نقش‌ها و ممیزی | ✅ ۵۳ آزمون |
| پیکربندی پویا (گروه اطلاعات/فیلد/فرمول DSL امن) | ✅ ۵۹ آزمون |
| طراح OPC/FPC + ارتباط دوطرفه فعالیت | ✅ ۳۸ آزمون |
| ثبت دستی زمان (برگه ثبت، وقفه‌ها، اصلاح با دلیل) | ✅ ۴۷ آزمون — **ADR-017** |
| سوابق جلسات کرنومتری (میراث، فقط‌مشاهده) | ✅ ۴۲ آزمون |
| تحلیل آماری + زنجیره زمان + گزارش‌ها | ✅ ۴۸ آزمون |
| بالانس خط (LCR/RPW/KW + دستی) + Yamazumi | ✅ ۵۶ آزمون |
| یکپارچه‌سازی، امنیت، PWA | ✅ ۷۵ آزمون |

**جمع آزمون‌های گذرنده:** ۲۴۳ واحد (هسته‌های مشترک) + ۴۱۸ یکپارچگی (فاز ۱–۷ + ثبت دستی) — شواهد: `docs/evidence/` و `docs/ux-verification/`.

## قابلیت‌های کلیدی

- **مدیریت پروژه‌های ایزوله** با نقش‌ها (owner/editor/recorder/viewer) و ممیزی کامل append-only.
- **پیکربندی پویا:** خانواده/پارامتر سفارشی + فرمول DSL امن (بدون eval) با نسخه‌بندی semver — بدون تغییر کد.
- **کارگاه فرم‌ساز** با شرط‌های نمایش/الزام پویا و ثبت مقادیر.
- **طراح نمودار OPC/FPC** گرافیکی (React Flow): خروجی SVG/PNG/چاپ RTL + اعتبارسنجی زنده + تاریخچه نسخه + variant مقایسه‌ای.
- **دستیار آفلاین** قواعد-محور (۱۱ قاعده پیشنهاد با دلیل + کتابخانه دانش محلی) — بدون اینترنت.
- **ثبت دستی زمان (مسیر اصلی — ADR-017):** برگه ثبت با جدول فعالیت × نمونه؛ تجزیه قالب‌های 12.5 / ۱۲٫۵ / 12,5 / 00:12.5 / 1:02:03.5 (ارقام فارسی/عربی/لاتین)؛ واحد استاندارد ms؛ وقفه با کاتالوگ علت و «سایر» الزامی‌متن؛ مدت نامشخص صادقانه؛ اصلاح با دلیل + ممیزی؛ وضعیت‌های پیش‌نویس/تکمیل/نهایی(در تحلیل).
- **سوابق کرنومتری (میراث):** جلسات event-sourced قبلی دست‌نخورده و قابل مشاهده باقی می‌مانند و در تحلیل همان‌طور استفاده می‌شوند.
- **تحلیل آماری:** آمار توصیفی/CV/چندک، دو قاعله پرت (IQR/z-score) جدا از حذف، کفایت نمونه، زنجیره زمان با دو قرارداد مجاز (on-normal/on-standard) و ردیابی فرمول نسخه‌دار.
- **بالانس خط:** سه الگوریتم قطعی (LCR · RPW Helgeson–Birnie · Kilbridge–Wester) + تخصیص دستی با اعتبارسنجی قیود سخت/نرم + Yamazumi/OBC + مقایسه سناریو + برآورد نیروی نظری/عملیاتی.
- **خروجی‌ها:** CSV (BOM فارسی) · XLS (SpreadsheetML RTL) · JSON با بلوک ردیابی کامل · چاپ A4 RTL.
- **PWA:** Service Worker (پوسته آفلاین + دارایی کش‌اول؛ API هرگز کش نمی‌شود) + manifest فارسی + نصب‌پذیری.

## شروع سریع

```bash
bun install
cp .env.example .env          # DATABASE_URL + NEXTAUTH_SECRET بسازید
bun run db:push
bun run seed                  # demo@timing.local / demo1234 + پروژه‌های نمونه DEMO-101 و DEMO-102
bun run dev                   # → http://localhost:3000
```

راهنمای کامل نصب/استقرار/پشتیبان‌گیری/عیب‌یابی: **`docs/DEPLOYMENT_FA.md`**
راهنمای کاربر فارسی: **`docs/USER_GUIDE_FA.md`**

## اصول کلیدی محصول

- **پیش‌فرض مهندسی‌شده + شخصی‌سازی حداکثری:** پروژه جدید هرگز خالی ایجاد نمی‌شود؛ پروفایل پیش‌فرض واقعی و قابل ویرایش است.
- **صداقت روش‌شناختی:** استانداردهای رسمی، روش‌های مرجع و مقدارهای پیشنهادی/وابسته به کارخانه از هم جدا می‌مانند؛ هیچ ضریبی بدون منبع «استاندارد جهانی» جلوه داده نمی‌شود.
- **استقلال پروژه‌ها:** ویرایش یک پروژه هیچ پروژه دیگری را تغییر نمی‌دهد؛ مجوزسنجی سمت سرور در همه APIها.
- **قابلیت ردیابی:** هر نتیجه به نسخه پیکربندی، نسخه فرمول و مشاهدات ورودی ارجاع دارد.
- **تست بدون شاهد، پذیرفته نیست:** وضعیت هر معیار در `docs/PHASE_STATUS.md` با شاهد ثبت می‌شود.
