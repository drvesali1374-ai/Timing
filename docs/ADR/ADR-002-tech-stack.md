# ADR-002: انتخاب فناوری پایه (Next.js 16 + TypeScript + Tailwind + shadcn/ui)

**وضعیت:** پذیرفته‌شده — **تاریخ:** ۲۹ اکتبر ۲۰۲۶ — **فاز:** صفر

## زمینه
نیازمندی‌ها: وب‌اپلیکیشن حرفه‌ای RTL فارسی، API سمت سرور برای مجوزسنجی (A5)، PWA/آفلاین (B12)، ویرایشگر نمودار سنگین (B6)، اجرای اختیاری مدل محلی (B7)، استقرار کم‌هزینه.

## تصمیم
**Next.js 16 (App Router) + TypeScript 5 + Tailwind CSS 4 + shadcn/ui (New York) + lucide-react.**
- API Routes برای همه عملیات (مجوزسنجی سرور، zod).
- Client Components برای ابزارهای تعاملی (کرنومتر، ویرایشگر نمودار).
- next-intl برای معماری چندزبانه با fa (RTL) به‌عنوان locale پیش‌فرض.

## ماتریس مقایسه
مجموع وزنی (۰–۹۰): Next.js **۸۹** · Vue/Nuxt ۷۳ · SPA خالص ۷۱ · Electron ۶۴ · Angular ۶۲.
جزئیات کامل ماتریس در `ARCHITECTURE.md` بند ۶.

## دلیل کلیدی
۱. یکپارچگی UI+API در یک قالب → مجوزسنجی سرور بدون CORS/دو-ریپوی.
۲. اکوسیستم React Flow/Recharts برای ویرایشگر و Yamazumi.
۳. PWA بالغ (Service Worker، manifest) برای آفلاین.
۴. پشتیبانی WebGPU در مرورگرهای مدرن برای لایه اختیاری مدل محلی.
۵. تجربه تیمی و ابزار lint/type موجود.

## نسخه‌های راستی‌آزمایی‌شده (npm ۲۰۲۶-۱۰-۲۹)
next 16.4.3 · react 19.3.1 · tailwindcss 4.3.3 · typescript 5.x — همه کانال پایدار.

## پیامدها
⚠️ وابستگی به اکوسیستم React (ریسک پذیرفته)؛ نیازمندی مرورگرهای مدرن (Edge/Chrome/Safari ۱۶+).
✅ یک ریپو، یک استقرار، یک زبان تایپ.
