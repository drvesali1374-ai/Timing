# ADR-003: موتور فرمول با پارسر اختصاصی امن (بدون eval)

**وضعیت:** پذیرفته‌شده — **تاریخ:** ۲۹ اکتبر ۲۰۲۶ — **فاز:** صفر (طراحی) / ۲ (پیاده‌سازی)

## زمینه
A8 سند جامم: «اجرای مستقیم کد دلخواه کاربر برای فرمول‌ها ممنوع است». B3: عملگرها، شرط، تجمیع، چند-سطحی، گراف وابستگی، trace، قطعیت.

## تصمیم
**پارسر بازگشتی-نزولی اختصاصی → AST → مفسر درخت** با گرامر EBNF محدود (`FORMULA_CATALOG.md` بند ۵).
- الگوی الهام‌گرفته از jsep v1.6 (MIT) برای ساختار tokenizer/parser؛ بدون وابستگی اجرایی.
- فهرست بسته توابع؛ بدون حلقه/تخصیص/دسترسی DOM/زمان سیستم.
- سقف‌ها: عمق ۶۴، طول ۲۰۴۸، گره ۵۱۲.

## گزینه‌های رد‌شده
- **mathjs (v15.2):** سطح حمله بزرگ‌تر (evaluate رشته)، حجم بالا، semanticهای عددی بیش از نیاز.
- **eval/Function/VM:** ممنوع مطلق (A8).
- **فرمول‌های ثابت کدنویسی‌شده:** نقض «شخصی‌سازی حداکثری» (A2).

## پیامدها
✅ کنترل کامل امنیت/نوع/واحد/trace؛ آزمون‌پذیری خالص؛ اندازه کوچک.
⚠️ هزینه نگهداری پارسر (پذیرفته؛ گرامر کوچک و قفل‌شده در فاز ۲).
