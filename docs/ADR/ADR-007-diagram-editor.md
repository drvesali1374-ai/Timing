# ADR-007: ویرایشگر نمودار بر پایه React Flow (@xyflow/react)

**وضعیت:** پذیرفته‌شده — **تاریخ:** ۲۹ اکتبر ۲۰۲۶ — **فاز:** صفر (طراحی) / ۳ (پیاده‌سازی)

## زمینه
B6: ویرایشگر OPC/FPC با drag-and-drop، اتصال جهت‌دار، چیدمان خودکار اولیه + ویرایش آزاد، zoom/pan، undo/redo، انتخاب چندگانه، خروجی چاپ/SVG/PNG، RTL بدون معکوس‌شدن پیکان‌های منطقی.

## تصمیم
**@xyflow/react v12** (نسخه راستی‌آزمایی‌شده npm ۲۰۲۶-۱۰-۲۹: 12.12.0؛ مجوز MIT) به‌عنوان بستر ویرایشگر:
- Node سفارشی برای نمادهای OPC/FPC (SVG).
- Edge جهت‌دار با waypoints قابل ویرایش؛ جهت معنایی مستقل از RTL.
- مدل معنایی (`DiagramDoc` در ENGINE_CONTRACTS) **جدا** از لایه نمایش/چیدمان.
- undo/redo با ذخیره تاریخچه نقطه‌چین مدل + چیدمان.

## گزینه‌های رد‌شده
- **GoJS:** تجاری (پرداخت/شرایط مجوز) — مغایر هزینه/آزادی پروژه.
- **بوم خام SVG/Canvas اختصاصی:** کنترل کامل اما هزینه ساخت ابزار پایه (zoom/pan/undo/اتصال) بالا و ریسک باگ.
- **DrawIO/Excalidraw embed:** مدل داده قابل‌کنترل نیست؛ خروجی استاندارد/خوانایی متاداده پروژه ندارد.

## پیامدها
✅ سرعت توسعه ابزار پایه + متن‌باز + اکوسیستم.
⚠️ سربار بسته (~tailwind-free CSS) قابل قبول؛ نیاز به تست RTL اختصاصی؛ قفل نسخه v12 در فاز ۳ با تست رگرسیون ارتقا.
