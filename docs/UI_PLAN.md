# طرح رابط کاربری و وایرفریم‌ها (UI PLAN)

**نسخه:** ۱٫۰ (فاز صفر) — **تاریخ:** ۲۹ اکتبر ۲۰۲۶
**زبان/جهت:** فارسی / RTL — **الگو:** shadcn/ui (New York) — **پاسخ‌گویی:** موبایل-اول، دسکتاپ-کامل
**نمونه قابل بررسی:** وایرفریم تعاملی ۸ صفحه در مسیر `/` پروژه (اجزای `src/components/prototype/`) — اجرای زنده از فاز صفر برای بازخورد کاربر.

---

## ۰. قواعد سراسری

- پوسته: هدر بالا (ناوبری اصلی + وضعیت آفلاین/همگام) + سایدبار پروژه (در دسکتاپ) + محتوا + فوتر چسبان.
- همه مسیرهای پروژه‌ای دارای Breadcrumb: `پروژه‌ها / {نام پروژه} / {بخش}`.
- وضعیت‌های الزامی همه صفحات: بارگذاری (Skeleton) · خطا (پیام + اقدام) · خالی (راهنمای گام بعد) · ذخیره/همگام.
- رنگ سازمانی: خنثی + تأکید سبز-زمینه‌ای (بدون آبی/بنفش پیش‌فرض)؛ تم روشن/تاریک.
- فوتر همیشه چسبان به پایین صفحه (flex + mt-auto).

## ۱. مسیرهای اصلی

| # | مسیر (App Router) | نام فارسی | نقش‌های مجاز |
|---|---|---|---|
| ۱ | `/` | داشبورد / مدیریت پروژه‌ها | همه (پس از ورود) |
| ۲ | `/projects/new` | ایجاد پروژه و انتخاب پروفایل | editor+ |
| ۳ | `/projects/[id]` | نمای کلی پروژه | مجوز پروژه |
| ۴ | `/projects/[id]/config` | کارگاه پیکربندی (خانواده/پارامتر/فرمول) | editor+ |
| ۵ | `/projects/[id]/timing` | صفحه زمان‌سنجی (کرنومتر) | recorder+ |
| ۶ | `/projects/[id]/diagrams` | نمودارهای OPC/FPC + دستیار آفلاین | editor+ |
| ۷ | `/projects/[id]/analysis` | تحلیل زمان و آمار | viewer+ |
| ۸ | `/projects/[id]/balance` | بالانس خط و نیروی کار | editor+ |
| ۹ | `/projects/[id]/reports` | گزارش‌ها و خروجی‌ها | viewer+ |

> در محیط پیش‌نمایش فاز صفر، هر ۸ مسیر اصلی به‌صورت «نمای وایرفریم» درون یک صفحه `/` با ناوبری داخلی شبیه‌سازی شده‌اند.

## ۲. وایرفریم‌ها (مهم‌ترین جریان‌ها)

### ۲٫۱. مدیریت پروژه‌ها (داشبورد)

```
┌────────────────────────────────────────────────────────────┐
│ ⏱ زمان‌سنج صنعتی   [جست‌وجو]            [＋ پروژه جدید]  وضعیت: ● آنلاین │
├──────────┬─────────────────────────────────────────────────┤
│ ناوبری    │ کارت پروژه‌ها (فیلتر: فعال/بایگانی/نمونه)         │
│ داشبورد   │ ┌──────────┐ ┌──────────┐ ┌──────────┐          │
│ پروژه‌ها   │ │ PRJ-001  │ │ PRJ-002  │ │ 🎓 نمونه │          │
│ …         │ │ خط مونتاژ│ │ بسته‌بندی│ │ آموزشی   │          │
│           │ │ آماده ⚠ │ │ در ثبت ● │ │ ایزوله   │          │
│           │ └──────────┘ └──────────┘ └──────────┘          │
├──────────┴─────────────────────────────────────────────────┤
```

داده هر کارت: عنوان، کد، وضعیت، نشانگرهای آمادگی (اندازه‌گیری/تحلیل/تأیید)، پروفایل، تاریخ.

### ۲٫۲. ایجاد پروژه + انتخاب پروفایل (کلیاتی حیاتی A2)

```
┌ گام ۱: اطلاعات پروژه ──────────── گام ۲: پروفایل ─ گام ۳: اجزا ┐
│ عنوان* کد* هدف محل/بخش/خط محصول فرایند مسئول شیفت یادداشت     │
├──────────────────────────────────────────────────────────────┤
│ پروفایل‌ها (پیش‌فرض انتخاب‌شده: ✔ مطالعه عمومی زمان صنعتی)      │
│ ┌ ✔ عمومی ILO-هم‌راستا ┐ ┌ پیوسته ┐ ┌ بازگشت به صفر ┐ …      │
│ │ منبع/نسخه/فرض‌ها      │ │ …      │ │ …              │       │
│ │ [پیش‌نمایش کامل]      │ └────────┘ └────────────────┘       │
│ └─────────────────────────────────────────────────────────────┘
│ اجزای پروفایل: ☑ خانواده زمینه ☑ ارزیابی عملکرد ☑ مجاز ۱۵٪   │
│ (مقدار پیشنهادی — ویرایش ✔) ☐ خانواده سفارشی                  │
│ [پروژه نمونه آموزشی جدا از داده واقعی]                         │
└──────────────────────────────────────────────────────────────┘
```
قاعده: پروفایل پیش‌فرض از ابتدا انتخاب است؛ پیش‌نمایش قبل از ایجاد؛ اجزا قابل برداشتن.

## ۳. جریان‌های کاربر کلیدی (پیش‌بینی آزمون E2E فاز ۷)

۱. ایجاد پروژه با پروفایل پیش‌فرض → ۲. افزودن پارامتر سفارشی → ۳. ساخت/ویرایش فرمول → ۴. رسم FPC → ۵. جلسه زمان‌سنجی چند چرخه → ۶. تحلیل و زنجیره استاندارد → ۷. سناریوی بالانس + مقایسه → ۸. گزارش نهایی با ردیابی نسخه.

## ۴. دسترس‌پذیری

- برچسب/aria برای همه کنترل‌ها؛ ناوبری کیبورد کامل؛ هدف لمسی ≥۴۴px؛ کنتراست AA؛ `lang="fa" dir="rtl"`.
- اعداد فارسی-اختیاری در نمایش؛ داده ذخیره ASCII-استاندارد.
